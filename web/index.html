Keelstamp receipt verifier

Checks a receipt's Ed25519 signature (COSE_Sign1), its canonical JSON payload (RFC 8785), its profile, the signing key, and its inclusion in the log: the log receipt it carries (COSE Receipt, RFC 9942 / RFC 9162) and, when given, a published checkpoint.

Pre-release: the format may change before Keelstamp is in operation. Everything runs inside this page. Its Content-Security-Policy blocks all network connections, so files you choose or paste are not sent anywhere.

Only this field is used for keys. The page never takes keys from the receipt or from a file that came with it. Once Keelstamp is in operation, its keys file will be published at /.well-known/keelstamp-keys.json and in its transparency repository.
